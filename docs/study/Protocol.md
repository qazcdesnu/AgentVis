# 진행 대본

이 문서는 수업 실험 미니 버전의 진행자가 참가자 한 명을 45분 안에 진행하는 순서와 안내 문구다. 동의서와 사후 설명도 여기 있다. 자료 준비는 [수업 실험 미니 버전 자료 묶음](Kit.md)에, 참가자가 답할 질문은 [과업지](TaskSheet.md)에 있다.

## 1. 준비 (참가자 오기 전)

- 참가자 번호(`P01`…)와 조합 번호(1\~4)를 [시행 구성](Kit.md#2-시행-구성)에서 정한다.
- 연습 블록의 실험 모드 서버를 띄운다. `uv run agentvis experiment <참가자>-practice --transcripts blocks/practice`
- 기준선 블록은 `--baseline`으로 띄운 실험 서버(2.1.0부터)를 쓴다. 2.0.x면 기준선 HTML을 브라우저 탭에 열어 두되 아직 보여 주지 않는다.
- 과업지를 기록마다 한 장씩, 블록 순서대로 준비한다.
- 시간을 잴 시계(초 단위)와 메모지를 둔다.

## 2. 진행 (45분)

| 시간 | 단계 | 진행자가 하는 일 |
| --- | --- | --- |
| 0\~5분 | 동의와 안내 | 3절의 동의서를 읽게 하고 서명을 받는다. [과업지의 안내](TaskSheet.md#안내)를 읽어 준다. 특히 "지시 가운데 일부에는 잘못이 있고, 일부에는 없다"를 강조한다. |
| 5\~10분 | 연습 | 연습 기록을 AgentVis 화면과 기준선 화면으로 한 번씩 보여 주고 각 화면의 기본 조작을 2분씩 설명한다. 연습 과업지를 풀게 하고 답을 알려 준다(연습 기록의 답: 원인을 `invoice.py`의 `round`로 잘못 짚었고, 에이전트는 알아채고 `discount.py`를 고쳤다). |
| 10\~22분 | 블록 1 | 조합의 첫 조건과 세트로 기록 2개. 기록마다 과업지를 주고 시작·끝 시각을 적는다. 기록을 보여 줄 때 머리줄의 `시행 n 시작`을, 과업지를 받을 때 `시행 n 끝`을 눌러 화면 사용 기록에도 남긴다(2.1.0부터는 기준선 블록도 같다). 기록 하나에 6분이 지나면 "1분 남았습니다"라고 알리고, 7분에 다음으로 넘어간다. |
| 22\~34분 | 블록 2 | 다른 조건과 세트로 같은 방식. AgentVis 블록이면 서버를 그 블록 폴더로 다시 띄운다. |
| 34\~37분 | U3 | 결정 지점에서 자른 기록을 마지막 조건의 화면으로 보여 주고 과업지 U3에 답하게 한다. |
| 37\~45분 | 사후 설문과 인터뷰 | 과업지의 사후 설문을 받은 뒤 아래 질문으로 인터뷰한다. 녹음은 동의한 경우에만 한다. |

**인터뷰 질문**
1. 어느 순간에 "지시가 이상하다"고 의심하기 시작했나요? 화면의 무엇을 보고 그랬나요?
2. 에이전트가 무엇을 했는지 파악할 때 어떤 순서로 화면을 봤나요?
3. 화면에서 방해가 되거나 필요 없던 정보는 무엇이었나요?
4. 실제로 코딩 에이전트를 쓸 때 이런 일을 겪은 적이 있나요?

**진행 중 지킬 것**
- 참가자가 답을 물으면 "지금 화면에서 찾을 수 있는 만큼 답해 주세요"라고만 한다. 정답을 암시하지 않는다.
- 화면 조작을 물으면 연습에서 설명한 범위 안에서만 답한다.
- 블록 사이에 참가자가 원하면 1분 쉰다.

## 3. 동의서

> **연구 참여 안내와 동의**
>
> 이 실험은 대학원 수업 과제로, 코딩 에이전트의 작업 기록을 보여 주는 화면이 사용자가 기록을 이해하는 데 도움이 되는지 알아보려는 것입니다.
>
> - 여러분은 미리 만든 작업 기록 몇 개를 두 가지 화면으로 보고 질문에 답합니다. 약 45분이 걸립니다.
> - 기록은 실험용으로 만든 것이며 여러분이나 다른 사람의 개인 작업이 아닙니다.
> - 답, 걸린 시간, 화면 사용 기록(누른 곳과 시각), 설문 응답을 모읍니다. 동의한 경우에만 인터뷰를 녹음합니다.
> - 자료는 참가자 번호로만 저장하고 이름과 연결하지 않습니다. 자료는 연구팀의 컴퓨터에만 두며, 수업이 끝난 뒤 학기 성적 처리 기간이 지나면 삭제합니다.
> - 결과는 수업 보고서에 참가자를 알아볼 수 없는 형태로만 씁니다. 학회 논문에는 쓰지 않습니다.
> - 참여는 자유이며, 언제든 이유 없이 그만둘 수 있고, 그만두어도 불이익이 없습니다. 그만두면 그때까지의 자료를 삭제합니다.
>
> 위 내용을 이해했고 참여에 동의합니다. ( ) 인터뷰 녹음에도 동의합니다.

## 4. 사후 설명 (끝난 뒤 읽어 준다)

> 실험에 참여해 주셔서 감사합니다. 오늘 보신 기록의 지시 가운데 일부에는 연구팀이 일부러 심은 잘못이 있었습니다. 실제 개발자가 코딩 에이전트에게 틀린 정보를 줄 때, 에이전트가 어떻게 대응하는지와 사용자가 그것을 알아챌 수 있는지를 알아보기 위해서였습니다. 처음 안내에서 "일부에는 잘못이 있다"고 말씀드린 것은 사실입니다. 다른 참가자가 아직 실험 전일 수 있으니, 오늘 본 기록과 답은 실험이 모두 끝날 때까지 다른 사람에게 말하지 말아 주세요.

## 5. 끝난 뒤

- 과업지와 동의서를 참가자 번호로 묶어 보관한다.
- 실험 데이터 디렉터리(`~/.agentvis/experiments/<참가자>-<블록>/`)의 `interactions.jsonl`을 연구팀 보관 위치로 옮긴다.
- 진행 중 생긴 일(서버 재시작, 시간 초과, 화면 문제)을 메모에 적는다. 사용한 AgentVis 버전(서버 시작 시 출력)도 적는다.
