## I62 연구 설계 교체: 사용자의 지시 오류를 중심으로 한 세 과업

- 시작일: 2026-11-12
- 근거 문서: [PR 규칙의 릴리스](PullRequestRule.md#6-릴리스), [고충 조사 6절](research/ClaudeCodePainPoints.md#6-사용자-쪽-오류에서-시작하는-고충)
- 관련 이슈: I26, I49, I51

### 계획
- 1.1.0을 처음 설계의 고정판으로 릴리스하고(I61), 새 설계는 2.0.0이라는 버전 규칙을 PR 규칙과 제출 계획에 적는다.
- 새 세 과업의 정의(질문, 필요한 정보, 정답, 실험 자료)를 과업 문서로 새로 쓴다. T1\~T6 문서는 지우지 않고 1.1.0 설계로 남긴다.
- 과업에 맞춰 화면에서 보일 정보와 접을 정보를 다시 정하고 로드맵에 등록한다.
- 최신 `main`에서 만든 `i62-research-redesign`에서 진행한다.

### 진행 기록
- 2026-11-12: 팀 회의 결과를 받았다. 사용자가 1.1.0은 그대로 만들어 고정하고, 새 설계는 저장소 스키마 못지않은 큰 바뀜이라 2.0.0으로 시작하라고 했다. PR #48\~#51 병합 뒤 `v1.1.0` 태그와 GitHub 릴리스를 만들었다.
